# Achilles Tendinopathy Rehab Tracker

Private, offline-friendly tracker for the Chronic Mid-Portion Achilles Tendinopathy rehabilitation program (6-month timeline).

## Features
- Day-by-day exercise logging (Isometric Hold, Two-Legged Raise, Single-Leg Raise, Weighted Raise)
- Tennis Day marker (automatically suggests skipping Two-Legged Raise)
- Full month calendar view
- Progress stats & history
- All data stays on the device (localStorage) — nothing is uploaded

## How to use
1. Open the page in any browser (Chrome recommended on Android, Safari on iOS).
2. Tap **Share → Add to Home Screen** to install it like an app.
3. Log exercises each day. Data saves automatically.
